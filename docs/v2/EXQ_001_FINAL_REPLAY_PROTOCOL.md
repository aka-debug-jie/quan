# EXQ-001 final candidate qualification replay

The final replay is additive. It never replaces `EXQ_001_RESULT.md`, the
frozen free-evidence funnel, or any raw source artifact. It reads two pinned
JSON objects: the legacy candidate qualification and a compiled current-evidence
object. Their bytes and SHA-256 identities are verified before a matrix is built.

Every exact residual dependency key is represented once. The full candidate
domain is assessed separately, so a clean residual subset cannot conceal missing
raw execution coverage elsewhere in the frozen CSI300 candidate domain.

Only an official notice published on or before the signal day and explicitly
establishing non-tradability can create an exclusion. Retrospective issuer
history, an empty provider response, adjusted Qlib data and future label
availability cannot do so. The current compiler preserves these states as
blocking evidence until a source-bound runner produces stronger evidence.

The three in-interval equity distributions remain
`FACTOR_RECONCILIATION_PENDING`. The macro lifecycle entries remain event records,
not trade, cash or member-history inferences. The replay always preserves
`FORMAL_PIT_STATUS=BLOCKED_DATA`, `FORMAL_RESEARCH_STATUS=BLOCKED_DATA` and
`CSI500=NOT_STARTED`.
