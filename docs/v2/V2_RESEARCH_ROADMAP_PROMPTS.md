# V2 后续研究路线与任务提示词

状态：`PLANNING_ONLY`。本文件把后续研究拆为有前置条件的任务单；它不授权
数据访问、模型训练、组合回测、CSI500 sealed 测试、模拟盘或实盘。以
`V2_DELIVERY_PROGRESS.md`、`V2_EXPERIMENT_CONTRACT.md` 和
`V2_EXTERNAL_VALIDATION_CONTRACT.md` 为准；发生冲突时，后三份既有合同优先。

## 固定起点

- 免费缺口证据：`CLOSED_WITH_RESIDUAL`。15,743 个缺口已唯一分类，其中
  15,203 个为官方停牌、540 个未解释、冲突为零。该 540 个残余不是待办队列。
- DEV-001：`DEV_REAL_RUN_COMPLETED`，只产生 CSI300 有限开发期的 Alpha158
  信号诊断；2020 年验证集已经被接触，不能作为未见外部测试。
- 正式 PIT 与正式研究：均为 `BLOCKED_DATA`；CSI500 为 `NOT_STARTED`。
- V1、既有冻结合同、历史 artifacts 与已结案免费审计不得改写。

每个任务均须先读取本文件、`AGENTS.md`、上述三份合同和当前交付进度；保留
失败实验、固定输入身份、代码提交、配置和结果 hash。没有写明授权的网络、
provider、sealed 数据访问、真实订单和定时任务一律禁止。

## 顺序与状态转换

```text
REL-01 → AF-001 → AF-002 → AF-003 → EXQ-001 → BT-001 → SEL-001
      → EXT-001 → REP-001 → PAPER-001 → ASTRA-001 → PORT-001
```

箭头表示前置条件，不表示自动执行。任何任务达到其停止条件后，应写入结果并
停止；后续任务需要单独批准。`EXQ-001` 之前不得报告组合收益；`EXT-001`
之前不得读取 CSI500 sealed 输入；`PAPER-001` 不授权实盘。

## AF-001：可解释单因子筛选

**前置：** REL-01 已完成；仅使用经批准的 CSI300 `LIMITED_DEV_RESEARCH` 视图。

**目标：** 注册并评价 12--20 个预先定义的量价因子，回答它们是否有稳定的
横截面预测方向。首轮只包含动量、短期反转、波动率、量价/流动性等数据语义已
确定的公式；不添加基本面、公告或新 provider。

**可直接使用的提示词：**

```text
任务：AF-001——第一轮可解释 A 股单因子筛选。

基于当前 V2 冻结状态，建立版本化 Alpha Registry。只使用已批准 CSI300 有限开发
视图和固定交易日历；不读取 CSI500、不访问网络、不新增数据源、不做组合收益或
参数搜索。预注册 12--20 个可解释量价因子，每项必须有 alpha_id、family、假设、
精确公式、预期方向、lookback、预测 horizon、所需字段、风险与固定评价规则。
按 T 时点可得信息计算，按既有 qlib_compat 标签及其依赖边界评价。输出日横截面
IC、Rank IC、ICIR、有效日期数、覆盖率、固定季度/年度分段、方向一致率、缺失率，
并保留所有失败项。不得用任何评价结果改写公式或选择日期。结果只可标记
REGISTERED、REJECTED_NO_STABLE_SIGNAL 或候选待 AF-002 复核，不能宣称 Alpha
发现、收益或正式资格。完成离线测试、静态检查、报告和提交后停止。
```

**晋级：** 不以总体 IC 为唯一标准；方向、覆盖和分段稳定性必须可审计。

## 全局停止规则

1. 开发范围无稳定信号：停止，不打开 sealed。
2. 仅单一时期有效：淘汰或降级，不能外推。
3. 复杂模型无稳定增量：保留简单模型。
4. 成本、延迟或执行约束后无边际：淘汰。
5. 外部复制失败：不能进入模拟账户。
6. 模拟盘有工程错误：先修工程，不能解释收益。
7. 任何测试结果参与改参：该测试失去未见资格。
