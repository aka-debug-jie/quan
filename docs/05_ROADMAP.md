# Roadmap

| Milestone | Scope | Promotion gate |
| --- | --- | --- |
| M0 | Contracts, models, offline fixture, CLI, CI | lint, types, tests pass |
| M1 | AKShare adapter, immutable snapshots, and local calendars | complete source-attributed data coverage |
| M2 | ETF features, weights, VectorBT adapter | no look-ahead; T+1 execution |
| M3 | Costs and robustness analysis | doubled costs and one-day delay reported |
| M4 | Paper broker and ledger | cash, holdings, orders, and fills reconcile |
| M5 | Daily automation | stale or invalid data stops the run |
| M6 | Isolated Qlib experiments | conventional baseline precedes ML |
| M7 | Live adapter, outside V1 | separate security and operational review |

M1 must not begin automatically as part of M0.
